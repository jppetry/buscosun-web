# seeding-kit.md — Community-Seeding für Tool-Landingpages

Transparente, **nicht-werbliche** Vorstellung der buscosun-Tools in relevanten
Communities. Regeln: zuerst Forenkultur/Selbstpromo-Regeln prüfen, ehrlich zu den
Grenzen (Beispieldaten, kein amtliches Briefing), als Hilfe posten, nicht als Ad.
Jeweils die passende **Funktionsseite** (`/funktionen/<slug>/`) verlinken — sie
hat OG-Großbild für ansprechende Einbettungen.

| Community | Winkel (Aufhänger) | Passendes Tool / Link |
|-----------|--------------------|------------------------|
| **Wetterzentrale-Forum** | Ehrlicher Modell-Spread statt Scheingenauigkeit; höhenkorrigierte Karte für DACH | `/funktionen/modellvergleich/`, `/funktionen/wetterkarte/` |
| **Gleitschirm-/Drachenflieger-Foren (z. B. DHV)** | Thermik & vertikale Schichtung, Föhn-Erkennung, 3D-Atmosphäre | `/funktionen/atmosphaere/`, `/wissen/thermik/`, `/wissen/foehn/` |
| **Ski-/Tourengeher-Communities** | Nebelobergrenze („über dem Nebel in der Sonne"), Schneefallgrenze, alpine Orte | `/funktionen/atmosphaere/`, `/wissen/nebel-hochnebel-nebelobergrenze/`, `/wissen/schneefallgrenze/` |
| **Rennrad-/Bikepacking-Foren** | Wetter entlang der Route zur Ankunftszeit, E-Bike-Reichweite | `/funktionen/tourenplanung/` |
| **astronomie.de / Astro-Communities** | Astro-Nacht & bester klarer Abend, Foto-Licht | `/funktionen/event-tag/` |
| **Foto-/Landschaftsfotografie-Foren** | Blaue Stunde, Foto-Licht, bester Tag der Woche | `/funktionen/event-tag/` |
| **Garten-/Imker-Foren** | Frost-/Regenfenster, Biowetter, Pollen | `/funktionen/arbeitsfenster/`, `/wissen/biowetter/` |
| **Drohnen-/Modellflug-Foren** | Böen-Schwellen als 48-h-Ampel (Go/No-Go) | `/funktionen/arbeitsfenster/`, `/wissen/windboeen-sturm/` |
| **Bau-/Handwerk-Communities** | Arbeitsfenster für Kran, Höhenarbeit, Anstrich | `/funktionen/arbeitsfenster/` |
| **r/de, r/Austria, r/wetter (Reddit)** | tracker-freie DACH-Wetter-App, ohne Konto | Home + passende Ortsseite |

## Vorgehen pro Post
1. Aktivität & Selbstpromo-Regeln der Community prüfen (Autonomie-Regel: extern).
2. Echten Mehrwert/Problembezug in den Aufhänger packen, nicht „schaut mein Tool".
3. Genau **eine** passende Funktionsseite verlinken (OG-Bild rendert die Vorschau).
4. Auf Rückfragen ehrlich antworten, inkl. Grenzen (Beispieldaten beim Globus,
   kein METAR/TAF, kein Lawinen-Datenprodukt).
